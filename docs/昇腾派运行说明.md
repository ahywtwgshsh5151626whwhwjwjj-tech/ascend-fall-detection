# 昇腾派运行说明

## 硬件与系统

- 设备：Orange Pi AIpro 20T
- NPU：Ascend 310B1
- 系统：Ubuntu 22.04.3 LTS，aarch64
- 项目目录：`/home/HwHiAiUser/ascend-edge-vision-demo`
- CANN 环境：`/usr/local/Ascend/ascend-toolkit/set_env.sh`
- Python：`/usr/local/miniconda3/bin/python3`

## 正式启动

登录昇腾派后执行：

```bash
cd ~/ascend-edge-vision-demo
source /usr/local/Ascend/ascend-toolkit/set_env.sh
export DISPLAY=:0
export XAUTHORITY=/home/HwHiAiUser/.Xauthority
export REHAB_SILENT=1
bash start.sh
```

`start.sh` 默认会启动稳定单路入口 `main_pose_safe.py`。需要声音测试时，明确设置：

```bash
export REHAB_SILENT=0
bash start.sh
```

## 手动启动正式入口

```bash
cd ~/ascend-edge-vision-demo
source /usr/local/Ascend/ascend-toolkit/set_env.sh
export DISPLAY=:0
export XAUTHORITY=/home/HwHiAiUser/.Xauthority
export REHAB_SILENT=1
python3 -u main_pose_safe.py
```

## 停止程序

```bash
pkill -TERM -f '[m]ain_pose_safe.py'
```

确认摄像头释放：

```bash
fuser /dev/video0 /dev/video1
```

## 正式文件对应关系

```text
main_pose_safe.py                 稳定单路 GUI 入口
main_pose.py                     融合引擎和音频告警集成
fall_ai/fall_engine.py           TCN + 规则 + 状态机
fall_ai/pose_fall_detector.py    YOLO Pose 解码、NMS、跟踪和姿态规则
fall_ai/alarm_manager.py         L1/L2 告警、确认、取消和 hard-negative 回流
models/yolov8n_pose.om           Ascend NPU 目标检测模型
fall_ai/runs/real/tcn_fall.npz   正式 TCN 权重
```

## 音频检查

```bash
aplay -l
python3 -c 'from utils.device import find_audio_output; print(find_audio_output())'
amixer -c 1 sget Speaker
```

当前设备实际使用过的 USB 声卡通常为 `hw:1,0`。只有 `REHAB_SILENT=0` 且检测确认跌倒时才会播放告警。

## 采集素材

采集工具位于：

```text
fall_ai/collect_dataset.py
```

图形采集工具按键：

```text
1  跌倒
2  非跌倒
p  暂停/恢复预览
q  退出
```

建议采集时使用独立输出目录，避免覆盖历史数据：

```bash
python3 -u fall_ai/collect_dataset.py --outdir ~/fall_dataset_round3 --duration 8 --fps 30 --no-beep
```
